Entry for the make.fun bounty
[One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629):
a program that writes one deadpan one-star review, at most 160 characters,
of an everyday essential to `/output/entry.txt`.

## The line

> Water has no flavour, costs money in a bottle, and still leaks through my
> roof. One star. Would not hydrate again.

114 characters — inside the 1–160 character gate.

The grievance is the sharpest true one water has: it is everywhere, it is
supposed to be free, and it still finds a way to cost you money and ruin
your ceiling. The turn lands in the last four words — a refund request
filed against hydration itself. Deadpan throughout: no exclamation marks,
no winking, one complaint, one line.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
deterministically — the same bytes on every run. Stdlib only, no network.
The output directory itself is never removed, only its contents.
